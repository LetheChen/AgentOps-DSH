# 适用范围

视频生产工作流生成产品介绍、功能演示和知识短视频时，从本目录选择模板。模板描述结构、节奏和字幕规则，不固化具体主题素材。

# 基础结构

- 开场在 3 秒内说明主题和观看收益。
- 主体按问题、过程、结果或功能模块分段，每个场景只承载一个主要信息点。
- 结尾给出结论、下一步动作或来源，不重复整段旁白。
- 16:9 用于演示和知识内容，9:16 用于移动端传播；同一内容跨比例复用时重新排版，不直接缩放。

# 节奏与时长

- 60 秒视频控制在 5 至 8 个场景，单场景通常 6 至 12 秒。
- 旁白、画面和字幕表达同一事实，不为追求节奏制造未出现在来源中的数字或结论。
- 转场服务于段落变化；连续操作演示优先硬切，不使用遮挡信息的全屏动效。

# 字幕与安全区

- 字幕避开平台操作栏和画面底部安全区。
- 关键文字保持足够的对比度，并在浅色与深色画面中分别检查。
- 图示、代码和表格在移动端仍要可读；无法保证时拆成多个场景。

# 交付检查

- 场景时长之和与目标时长误差不超过 5%。
- 每个场景都有旁白、画面提示和素材来源。
- 输出前检查空白帧、字幕溢出、音画不同步和未替换的占位文本。
