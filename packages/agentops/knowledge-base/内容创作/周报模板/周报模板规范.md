# 使用方式

周报工作流按本模板组织周期进展、关键指标、风险与下周计划。历史周报保留在同类目下，用于对照措辞和追踪跨周闭环。

# 固定结构

1. 周期：写明起止日期和统计范围。
2. 本周进展：按项目或业务域归并，保留专有名词和可验证结果。
3. 关键指标：给出指标值、比较基线和时间范围；缺失数据明确标注。
4. 风险与阻塞：说明影响、当前责任方和需要的决策。
5. 下周计划：写可验收的动作和完成条件，不写泛泛目标。

# 写作规则

- 以事实和结果为主，不把投入时长等同于产出。
- 同一事项只在最合适的一节出现，跨周延续项注明上一周期状态。
- 不编造数字；无法核实的判断写成待确认项。
- 面向管理阅读，优先保留影响范围、变化和决策点。

# 归档检查

- 周期、来源和生成时间完整。
- 指标有口径或来源说明。
- 风险和计划能一一对应。
- 输出文件与知识库页面内容一致。
