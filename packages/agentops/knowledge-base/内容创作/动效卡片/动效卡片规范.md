---

# 适用范围

动效卡片用于会话看板中的指标、进度、状态和对比展示。卡片是结构化结果的呈现层，不承担模型推理。

# 数据与状态

- 每张卡片使用稳定的 `viewId`；同一主题的新数据更新原卡片，不创建重复卡片。
- 状态至少覆盖加载、部分结果、完成和失败；失败状态说明可执行的下一步。
- 数字、单位和时间范围必须来自工具结果，并保留可追溯的来源或任务关联。

# 动效规则

- 入场动画只用于建立层级，不延迟首屏关键信息。
- 进度变化采用位置或尺度变化，避免频繁闪烁和循环装饰动画。
- 图表更新时保留坐标范围和视觉映射，防止动画让用户误判趋势。
- 低性能设备或减少动态效果设置下仍能直接读取最终状态。

# 排版

- 标题、主指标和说明形成单一阅读路径。
- 同时展示的内容保持一致的字体层级和间距，不使用多余颜色强调同级信息。
- 长标题允许换行；数字和单位保持同一行，表格在窄屏下切换为分段列表。

# 验收

- 无数据、加载中、部分结果、完成和错误状态都有可见反馈。
- 卡片在浅色和深色主题下均可读。
- 动效结束后，所有信息仍可从静态画面获得。
