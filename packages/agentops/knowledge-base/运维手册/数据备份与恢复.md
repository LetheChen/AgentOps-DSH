title: 数据备份与恢复
---

# 备份范围

生产数据库（业务库、审计库）、对象存储增量、配置与密钥元数据。会话日志与运行产物不纳入备份范围。

# 备份频率与保留

数据库每日 02:00 全量备份，每小时增量；全量保留 30 天，每季度首日的全量额外保留 12 个月。对象存储按周增量，保留 90 天。

# 备份校验

每次全量备份完成后自动执行一致性校验：记录数抽样比对与恢复演练库导入。校验失败按 P1 处理，当日必须重跑。

# 恢复演练

每季度一次恢复演练，覆盖单表恢复与整库恢复。演练记录包含恢复耗时、数据断点与验证结论，未演练的季度视为不达标。

# 恢复流程

1. 确认故障范围，冻结相关写入
2. 选择最近可用备份点并说明数据断点
3. 在隔离环境先恢复验证，再切主
4. 恢复后执行一致性核对并解冻写入

# 密钥与凭证

备份文件加密存储，密钥与备份分离保存。恢复时必须由两名运维同时在场操作，操作记录留档 3 年。
