# 会议目标

明确知识库的一级目录边界、文档归档判定顺序，以及 Wiki 工作台的审核与发布流程。

# 结论

- 财务制度、人事政策、运维手册、项目分析报告保持平面结构，不再设置二级目录。
- 办公协作承接周报、会议记录、系统规划和任务总结。
- 学习资料承接课程、书籍文章和学习笔记。
- 技术文档承接架构、接口、部署、故障排查和工程规范。
- 业务资产按业务划分为智能问数和智能审批，分别承接问数口径/查询方法与审批数据目录/能力边界。
- 内容创作继续承接视频、动效与周报模板。
- 无法确定归属的材料进入待复核，不强行归档。

# 后续

1. Agent 先判断文档的长期用途和所有者，再看文档标题中的体裁词。
2. 一级域确定后，仅在有分类的知识域内选择二级目录。
3. 发布前检查重复、敏感信息、来源和分类置信度。
