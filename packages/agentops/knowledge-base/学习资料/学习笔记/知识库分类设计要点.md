# 分类的目标

分类首先服务于长期查找和复用，而不是复刻文件系统。一个好的知识库应让读者先知道知识属于哪个宏观领域，再通过文档类型和来源快速缩小范围。

# 判定顺序

1. 识别知识的主要服务对象：企业制度、办公协作、项目研究、技术实现、学习吸收、业务资产或内容资产。
2. 识别文档用途：记录、方案、规范、分析、教程、模板或查询口径。
3. 只有分类稳定的知识域才继续分二级目录；平面知识域直接存放文档。
4. 置信度不足时进入待复核，不通过猜测制造错误分类。

# 避免的模式

- 按文件扩展名分类。
- 为单个项目、日期或作者建立目录。
- 同一文档复制到多个一级域。
- 把“周报”同时当作业务领域和文档类型。
