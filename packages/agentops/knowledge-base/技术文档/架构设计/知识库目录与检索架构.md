# 目录层

知识库一级目录表示长期稳定的知识领域；二级目录只在同一领域内存在稳定、可复用的文档类型时启用。财务、人事、运维和项目分析采用平面结构。

# 文档层

每篇文档保留唯一标识、标题、正文、来源和空间标识。分类目录由语料目录或 Wiki 发布时选择的路径确定。文档内容哈希决定是否产生新版本；目录移动只更新分类元数据。

# 检索层

BM25 在可读空间内检索当前版本。搜索结果返回空间、分类、文档和段落定位；目录层级不改变权限，权限仍由知识空间控制。

# 归档层

Agent 先判断知识领域，再判断文档类型。分类失败进入待复核空间。自动分类和人工确认都写入操作日志，保证归档过程可追溯。
