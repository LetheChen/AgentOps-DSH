## 这两类为什么不算"我们改了 DSH"

- 已抽验 blob SHA 完全相同（例：`scripts/check-expected-filenames.sh` 两侧都是 `bf10e2e6…`）；
- 只影响 DSH 自己的测试脚本与可执行入口，**不影响 AgentOps 的任何代码路径**；
- 想彻底消除：在一台能创建符号链接的 Linux/macOS 上检出，或在 Windows 开启开发者模式后 `git config core.symlinks true && git checkout -- .`（会重写这些路径，需先确认无本地改动）。

新增条目必须同样满足"blob 相同、只是模式差异"，否则请走 `DSH-CORE-CHANGES.md` 登记。
